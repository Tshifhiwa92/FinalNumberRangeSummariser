Number Range Summarizer
Overview

The Number Range Summarizer is a Java application that takes a comma-delimited list of integers and summarises consecutive numbers into ranges.

For example:

Input:
1,3,6,7,8,12,13,14,15,21,22,23,24,31

Output:
1,3,6-8,12-15,21-24,31

The implementation is designed using object-oriented principles, with a clear separation between the interface, domain model, implementation logic, and tests.
